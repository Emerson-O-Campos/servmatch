# FindPro - Plataforma de Contratação de Serviços

## Sobre o Projeto
FindPro é uma plataforma que conecta clientes a prestadores de serviços.

## Funcionalidades
- 🔍 Busca inteligente de profissionais
- 👤 Cadastro de clientes e prestadores
- ⭐ Sistema de avaliações
- 📋 Gerenciamento de pedidos
- 📍 Geolocalização
- 📊 Dashboard com gráficos

## Como executar
1. Clone o repositório
2. Configure suas credenciais do Firebase no arquivo `js/config.js`
3. Abra o `index.html` no navegador

## Configuração do Firebase
1. Crie um projeto no Firebase
2. Habilite Authentication (email/senha)
3. Crie um banco Firestore
4. Copie as regras do `firestore.rules`
5. Configure seu `js/config.js` baseado no `config-template.js`

## Tecnologias
- HTML5, CSS3, JavaScript
- Firebase (Auth, Firestore)
- Chart.js
